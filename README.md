# Research Idea Screening

快速研究点子筛选工作流。在生成大量研究点子后，用这个工作流快速筛选出值得深入评估的方向。

## 用途

- 从研究点子池中快速排除明显不可行的方向
- 标准化筛选标准（新颖性、可行性、契合度）
- 生成筛选报告，记录每条点子的审查结论

## 工作流

1. 加载点子池（从 research-ideation 的 `待评估点子.md` 或手动输入）
2. 逐条快速评估（5 维度评分，每维度 1 分钟上限）
3. 输出筛选报告：保留 / 待定 / 排除
